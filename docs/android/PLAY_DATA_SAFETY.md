# ELYIO Android V1 — Play Data Safety inventory

Status: evidence inventory for later Play Console completion; nothing submitted. Values are based on inspected source at commit `b8046c8aead4ce208a6b116c140812960a56fbe3`; provider dashboards, server-log retention and Play account details are not independently verified.

| Data | Collected/shared | Purpose | Required? | Retention/source |
|---|---|---|---|---|
| Camera image | Sent from browser to ELYIO FastAPI `/v1/recognize`; recognition providers may process it server-side. Not sent to GA/PostHog event payloads. | Artwork recognition and AI fallback. | Required for a scan; camera permission optional to app use. | Backend `RecognitionAttempt.response_payload` and operational logs can persist results; no universal deletion period is implemented. Current local visit can retain data-URL images. Verify provider/log retention before declaration. |
| Recognition outcome/diagnostics | ELYIO backend stores attempt ID, anonymous/session IDs, museum/artwork IDs, outcome, confidence, mode, latency and response JSON. | Reliability, idempotency, product operations. | Operational for recognition service; no login required. | Database model and backend code; exact DB backup/log retention unknown. |
| IP/server request metadata | FastAPI/hosting/platform logs may receive IP, user-agent and request metadata. | Security, abuse prevention, operations. | Usually automatic service operation. | Fly/provider log policy not inspected; verify before declaring. |
| GA4 | Consent-gated in web code; page views and explicit business events may include locale, museum/artwork IDs and coarse device/OS/browser/path parameters. | Visit funnel and activation measurement. | Optional; denial must not block scanning. | Google-managed retention/settings not visible in repository; verify property controls. |
| PostHog | Configured only when `NEXT_PUBLIC_POSTHOG_KEY` exists. Current A2 code now gates `track()` behind the same explicit analytics consent. Autocapture, replay and heatmaps are disabled in source. | Explicit product analytics. | Optional; denial must not block scanning. | PostHog US host is source default; project retention/settings require verification. |
| First-party/acquisition analytics | `/v1/events`, attribution and acquisition endpoints receive anonymous/session IDs, event names, UTM/referrer, locale/device/path and product IDs. A2 aligns this optional transport with consent. | Funnel/operations analytics. | Optional; denial must not block scanning. | Backend ProductEvent and acquisition service persistence; retention not established in source. |
| Location | Browser geolocation is requested to suggest a nearby museum; coordinates are used locally to choose a museum and are not fields in the recognition request. Selected museum ID/context can be sent with recognition/events. | Optional museum enrichment. | Optional; denial leaves scanner usable. | Coordinates local transient; selected context persists in current visit localStorage. Verify browser/provider logs. |
| Guest/session identifiers | `elyio-anonymous-id` localStorage UUID, sessionStorage session UUID, acquisition UUID and recognition attempt UUID. | Correlation, idempotency and analytics. | Scanning remains possible if storage fails. | Local storage until clear/eviction; backend attempt/event rows have unknown retention. Not secure account credentials. |
| Supabase account data | Only if user voluntarily signs in in future/current web auth path; email/provider/user ID can be sent to Supabase and backend user row. Not required for Android V1 scan. | Optional saved visit/auth. | Optional. | Supabase/backend account policies require verification. |
| Crash/error data | No dedicated native crash SDK in A2. Browser errors and sanitized recognition diagnostics may reach existing operational logs/events. | Reliability/debugging. | No native collection planned. | Provider retention unknown; do not declare a crash SDK that is not present. |

Transient vs persistent: the recognition request is transmitted for processing and may create a persistent `RecognitionAttempt`; this is not guaranteed ephemeral. Local current-visit JSON may include captured JPEG base64 and pending retry data; A2 bounds it at approximately 4 MB and removes older visitor-capture URLs first. IndexedDB multi-visit history is not implemented. No service worker caches camera/API data.

Before submission, verify actual production environment variables, GA4/PostHog receipt and settings, acquisition endpoint/CSP behavior, OpenAI/provider retention, Fly logs/backups, Supabase settings, privacy-policy wording, account type and Play form taxonomy. Do not infer “not collected” from absence of a native SDK when the hosted WebView performs the collection.
