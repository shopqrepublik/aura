# ELYIO Museum Keyword Map — V1 (17 museums × 3 locales)

Methodology: real-market qualitative SERP/search-intent research per museum per locale (English, French, Simplified Chinese researched separately, not mechanically translated). No search volume is fabricated — clusters are classified by search intent, apparent competition, relevance to ELYIO, conversion potential, content opportunity, and priority (HIGH/MEDIUM/LOW), per docs instructions. Facts verified against official museum sites and Wikipedia where practical; verification gaps are noted per-museum in the content data file (`web/lib/data/museums-v1.json`, field `imageConfidence`).

Status legend: **PRODUCTION_CATALOG** = ELYIO has a live curated recognition catalog. **CONTROLLED_PREVIEW** = onboarded in ELYIO's database but recognition not yet public (CTA routes to the generic scanner, no institution id passed). **NO_INSTITUTION_RECORD** = no ELYIO database entry at all (generic scanner only).
