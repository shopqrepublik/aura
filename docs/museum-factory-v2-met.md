# Museum Factory V2 — The Met

The Met profile uses the official Collection API and Open Access primary image
URLs. The first gate is a single deterministic canary (`437881`, *Young Woman
with a Water Pitcher*, Johannes Vermeer) through the same normalized-json and
generic ingestion path used by every museum. Public exposure remains disabled.

The canary must complete before selecting the initial representative painting
tranche; no Met-specific recognition or persistence architecture is allowed.
